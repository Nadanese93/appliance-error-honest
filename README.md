An electric kettle's boil-dry error message, written as if the machine is
honestly reporting what just happened: it boiled dry, it switched itself
off before a fire could start, and the user switched it straight back on.
The joke lands because the kettle is not trying to be funny — it is just
telling the truth about a real fault and a very human response to it.

## Entry

```
ERROR E01: Boiled dry. I switched myself off before the fire started. You switched me straight back on.
```

Run `python3 main.py` to write the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
